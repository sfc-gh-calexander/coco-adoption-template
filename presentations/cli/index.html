CoCo CLI

A terminal-native AI agent that connects your local dev environment to your data stack. Query data, build pipelines, and manage Snowflake resources in plain English, without leaving the terminal. This guide covers install, connecting to your Snowflake account, and your first query.

Prerequisite: your Snowflake role needs SNOWFLAKE.CORTEX_USER (granted to PUBLIC on most accounts by default) or SNOWFLAKE.CORTEX_AGENT_USER for agent-building features. You'll also need a terminal - bash, zsh, or fish on macOS/Linux, PowerShell on Windows.

New here? Start with Install and work through the tabs in order.

Step 1 of 4

Install

One script, no separate download page.

macOS / Linux / Windows (WSL)

curl -LsS https://ai.snowflake.com/static/cc-scripts/install.sh | sh

Windows (native, PowerShell)

irm https://ai.snowflake.com/static/cc-scripts/install.ps1 | iex

When prompted to add cortex to your PATH, respond y. Open a new terminal window afterward so the updated PATH takes effect.

Gate - do not advance until

cortex --version returns a version number instead of "command not found."

Step 2 of 4

Connect to Snowflake

Launch the CLI to start the setup wizard:

cortex

Use an existing connection

If you already have connections defined in ~/.snowflake/connections.toml (for example, from the Snowflake CLI), they appear in a list - select one and press Enter.

Or create a new one

Select More options and follow the prompts:

  • Account identifier (for example SFSENORTHAMERICA-XXXXX)
  • Username
  • Authentication method
If the connection fails: double-check the account identifier format and that your role has SNOWFLAKE.CORTEX_USER or SNOWFLAKE.CORTEX_AGENT_USER.
Gate - do not advance until

The wizard confirms a successful connection and drops you into a CoCo session.

Step 3 of 4

Run Your First Query

Ask something simple in plain English and confirm you get a real answer back from your own account.

  • "What tables do I have access to?"
  • "Show me the row count for my largest table."
  • "Describe the schema of <table_name>."

Behind the scenes, CoCo writes and runs the SQL for you and shows you what it ran - nothing happens silently.

Exit condition

CoCo answered a question using your actual Snowflake data, and you saw the SQL it ran.

Step 4 of 4

Keep Going

A few things worth knowing for day-to-day use.

Resume your last session

cortex --continue

Jumps straight into your most recent session instead of starting fresh.

Branch a session

Starting a new session from the current point creates a branch, so you can try something different without losing where you were.

Model access

CoCo uses whichever Cortex models your role has access to - Claude, OpenAI GPT, Gemini, and Grok models among others. New models are added as they're released.

Connect your other tools

CoCo CLI connects to external tools through the Model Context Protocol (MCP), the same mechanism CoCo Desktop uses for Google Workspace, Jira, GitHub, and more.

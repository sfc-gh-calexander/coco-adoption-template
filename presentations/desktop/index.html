CoCo Desktop

A native macOS/Windows IDE: file editor, integrated terminal, and an AI agent with deep Snowflake awareness, side by side. This guide covers download, connecting to your Snowflake account, and your first session.

Prerequisite: your Snowflake role needs SNOWFLAKE.CORTEX_USER (granted to PUBLIC on most accounts by default) or SNOWFLAKE.CORTEX_AGENT_USER for agent-building features.

New here? Start with Install and work through the tabs in order.

Step 2 of 4

Connect to Snowflake

On first launch, CoCo Desktop walks you through a four-step setup flow: welcome, connect, mode, theme.

Connect step

  • If you already have a ~/.snowflake/connections.toml file (for example, from the CLI), your existing connections appear automatically - just select one
  • Otherwise, select authentication method "Sign in with SSO" and authenticate through your organization's identity provider - CoCo establishes a secure connection automatically, no manual config file editing required
Mode step: next you'll choose a default warehouse for new sessions. CoCo saves this to your Snowflake user (ALTER USER SET DEFAULT_WAREHOUSE) and to your local connections.toml, so you don't set it again each session.

Confirm the connection

Once you're in the app, your active connection name appears in the top navigation bar. A green status dot next to it confirms you're connected.

If the connection failed: click the connection name, select Manage Snowflake Connections, and verify your account identifier and authentication method.

Step 3 of 4

Your First Session

CoCo Desktop has two modes. Which one you use depends on how you want to work.

Agent ModeChat-first. Three regions in the window, agent front and center.Letting the agent drive multi-step tasks across projects
Editor ModeStandard VS Code layout with the agent in a side panel.Writing and reviewing code yourself, with the agent alongside

Try it

  • Use the chat input at the bottom: type a message in plain English
  • Type / to invoke a skill (for example /semantic-view)
  • Type @ to attach a file or paste its contents into context

Ask something simple first: "What tables do I have access to?" or "Show me the row count for my largest table." Confirm you get a real answer back from your own account before doing anything more involved.

Step 4 of 4

Modes and Settings

A few things worth knowing once you're connected.

Connect your other tools

CoCo Desktop supports MCP (Model Context Protocol) servers for connecting to tools like Google Workspace, Jira, GitHub, and more. Configure them in Agent settings › MCP Servers, or ask your Snowflake admin to enable account-level connectors.

Cost controls

An account admin can set CORTEX_CODE_DESKTOP_DAILY_EST_CREDIT_LIMIT_PER_USER to control spend, including setting it to 0 to block access by default and allowlisting individual users.

Model access

CoCo uses whichever Cortex models your role has access to. Use the model picker in the chat input to see or switch models. If a model isn't available in your region, an ACCOUNTADMIN can enable cross-region inference.

Working offline

CoCo Desktop runs locally on your machine. If you close the app or shut down, active sessions pause - reopen the app to resume them.
